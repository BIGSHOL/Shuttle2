# 기사 사용 메뉴얼

셔틀이(Shuttlee)에서 운행을 담당하는 기사를 위한 가이드. 모바일(안드로이드 권장) 사용을 전제로 합니다.

> 📌 **전제**: 학원장이 미리 직원 초대 토큰을 보내야 가입 가능합니다. SMS·카카오톡으로 받은 URL부터 시작합니다.

## 1. 가입·로그인

### 1.1 토큰 가입

학원장이 보낸 초대 URL(`/invite/[token]`)에 접속.

![토큰 가입 화면](screenshots/driver/01-invite-signup.png)

1. **로그인 ID** 정하기 (영문·숫자·_, 4~20자, 예: `kim_driver`)
2. 비밀번호 (8자 이상)
3. **복구 이메일** (선택) — 비밀번호 재설정에 사용

> 💡 **TIP**: 로그인 ID는 학원장이 알려준 그대로 쓰거나 직접 정해도 됩니다. 한 번 정하면 변경 어려우니 신중히.

### 1.2 로그인

이후엔 `/login`에서 로그인 ID + 비밀번호로 진입.

![로그인 화면](screenshots/driver/02-login.png)

## 3. 운행 시작·권한 허용

운행 카드의 "운행 시작" 버튼 → GPS·알림 권한 popup이 차례로 뜹니다.

![GPS·알림 권한 popup](screenshots/driver/04-permissions.png)

**모두 "허용" 필수**:
- **위치** — 학부모·학원장에 실시간 위치 전송
- **알림** — 결석 통보·미탑승 보고 응답 받기

> ⚠️ **WARNING**: 거부 시 운행이 정상 작동하지 않습니다. 이미 거부했다면 브라우저 사이트 설정에서 다시 허용으로 변경.

---

## 4. 운행 화면 구조

운행 시작 후 dark gradient 헤더 + 정류장 진행도 + 학생 토글 화면.

![운행 화면 전체](screenshots/driver/05-trip-running.png)

### 4.1 헤더 칩 의미

![헤더 칩](screenshots/driver/06-trip-header-chips.png)

- **화면잠금 켜짐/꺼짐** — Wake Lock API. 켜져 있으면 화면 자동 꺼짐 방지.
- **위치 ±N m** — 현재 GPS 정확도. N이 작을수록 정확.
- **기사·동승** — 본인 + 지정된 동승보호자

### 4.2 경과 시간

운행 시작 후 흐른 시간(MM:SS)이 우측 상단에 카운트.

## 5. 안전점검 (어린이용 모드)

KIDS 모드 차량은 운행 시작·종료 시 안전점검 항목이 강제 노출됩니다.

### 5.1 출발 전 안전점검

![출발 전 안전점검](screenshots/driver/07-safety-check-pre.png)

- **좌석 안전띠 전원 확인** — 운행 전 모든 학생 안전띠 채워졌는지
- **동승보호자 동승 확인** — 도로교통법 §53⑦ 의무

체크 시 즉시 DB에 기록 → 안전운행기록 PDF에 자동 누적.

---

## 6. 동승보호자 지정

KIDS 모드 운행에 동승보호자가 필요. /run에서 운행 시작 후 헤더 아래 동승자 picker.

![동승보호자 지정](screenshots/driver/08-helper-picker.png)

- 등록된 동승자(HELPER 역할 직원) 중 선택
- "동승자 없음" 선택 가능하나 KIDS 모드에선 destructive 경고 표시

> ⚠️ **WARNING**: 동승자 없는 KIDS 운행은 도로교통법 위반. 운행 시작은 가능하나 사고 시 면책 자료 무효.

---

## 7. 정류장 자동 통과

GPS가 정류장 반경 50m 안에 들어오면 자동으로 통과(✓) 표시 + STOP_PASS ping 저장.

![정류장 통과 자동 감지](screenshots/driver/09-stop-passed.png)

- 통과한 정류장: 회색 + 취소선
- 다음 정류장: 강조

---

## 8. 학생 탑승·하차 처리

각 정류장 아래 배정된 학생 list. 학생 카드 탭으로 BOARD/ALIGHT 토글.

![학생 탑승 토글](screenshots/driver/10-student-toggle.png)

- 등원(PICKUP): 학생 탭 → BOARD ✓ (탑승 완료)
- 하원(DROPOFF): 학생 탭 → ALIGHT ✓ (하차 완료)

---

## 9. 미탑승·미하차 보고

학생이 정류장에 안 나옴(NO_SHOW) / 셔틀에서 안 내림(NO_DROPOFF) 시 빨간 ⚠️ 버튼.

![미탑승 보고 모달](screenshots/driver/11-no-show-report.png)

1. ⚠️ 버튼 → 사유 입력 모달
2. 사유 입력 (예: "부모님과 통화했으나 안 나옴")
3. 보고 → 학부모·학원장에 즉시 푸시

> ⚠️ **NO_DROPOFF은 매우 위험** — 학생이 셔틀에서 못 내린 경우. 보호자 미도착·잠들어 있음 등 사유와 후속 조치 명시 필수.

## 10. 결석 학생 표시

학부모가 결석 신청한 학생은 자동으로 회색 + "결석" 뱃지 + 사유 표시.

![결석 학생 표시](screenshots/driver/12-absent-student.png)

탑승 토글 자체는 막지 않음 — 학부모가 마지막에 사정 변경됐을 수 있음.

---

## 11. 60초 미처리 강조

정류장을 통과한 뒤 60초가 지났는데도 처리되지 않은(미체크 + issue 없음 + 결석 ACK 아님) 학생은 노란 깜빡임 + "처리 누락" 뱃지로 강조.

![60초 미처리 강조](screenshots/driver/13-stop-expired.png)

기사가 학생 처리를 잊은 케이스 시각 보강 — NO_SHOW 누락 위험을 다층으로 차단.

## 15. iPhone 사용자 주의사항

iOS Safari PWA는 **백그라운드 GPS가 거의 작동하지 않습니다**. 화면을 잠그거나 다른 앱을 켜면 위치 송신이 멈춥니다.

![iPhone Wake Lock 미지원 안내](screenshots/driver/18-iphone-warning.png)

### 권장 조치

1. **거치대 + 충전기** 필수 — 화면 켠 채로 운행
2. 화면 자동 꺼짐 방지가 안 되므로 **수동으로 화면 깨워두기**
3. 가능하면 **안드로이드 폰**으로 교체 — Wake Lock API 지원

> 📌 **NOTE**: 베타 기간엔 안드로이드 권장. iOS 네이티브 앱은 W14 이후 검토.
